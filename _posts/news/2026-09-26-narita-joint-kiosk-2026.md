나리타공항으로 들어갈 때 입국 절차가 조금 빨라집니다.
**9월 24일부터 나리타 제1·2터미널에 '공동 키오스크'가 생겼습니다.**

예전엔 입국심사대에서 여권 한 번, 세관에서 또 한 번 보여줘야 했잖아요.
이 키오스크에서는 **입국심사랑 세관신고에 필요한 정보를 한 번에** 낼 수 있습니다.

## 뭐가 바뀌나

[일본 재무성 관세국과 출입국재류관리청이 9월 18일 낸 발표](https://www.customs.go.jp/kaigairyoko/20260918.html) 내용입니다.

| 항목 | 내용 |
| --- | --- |
| 시작일 | 2026년 9월 24일 |
| 장소 | 나리타공항 제1·제2터미널 |
| 대수 | 177대 |
| 필요한 것 | Visit Japan Web QR코드 + 전자여권 |
| 한 번에 내는 정보 | 여권 정보, 얼굴 사진, 세관 신고 내용 |

키오스크 177대는 파나소닉 커넥트가 납품했다고 [발표](https://news.panasonic.com/jp/press/jn260918-2)했습니다.

## 이미 쓰고 있는 공항

나리타 1·2터미널이 새로 추가된 거고, 이 공항들은 원래부터 운영하고 있었습니다.

| 공항 | 터미널 |
| --- | --- |
| 하네다 | 제2·제3터미널 |
| 간사이 | 제1·제2터미널 |
| 나리타 | 제3터미널 (+ 이번에 1·2터미널) |
| 후쿠오카 | 국제선 |

한국에서 많이 가는 일본 큰 공항은 이제 거의 다 된다고 보시면 됩니다.

## 입국 순서

외국인 여행자 기준으로 이렇게 됩니다.

1. **공동 키오스크**에 Visit Japan Web QR코드랑 여권을 찍고, 화면 안내대로 진행
2. **키오스크 이용자 전용 입국심사 부스**에서 입국심사
3. 짐 찾고 세관으로 가서, 검사가 필요 없다고 나오면 **얼굴 인식으로 그냥 통과**

여기서 헷갈리면 안 되는 게 있습니다.
**키오스크가 입국심사를 대신해주는 건 아닙니다.**
키오스크를 써도 심사관한테 입국심사는 받아야 하고, 세관 판단에 따라 짐 검사를 할 수도 있어요.
그래도 여권을 여러 번 꺼낼 일이 줄고, 전용 부스로 가니까 전체 시간은 확실히 줄어듭니다.

## 비행기 타기 전에 해둘 것

제일 중요한 건 **Visit Japan Web 등록을 미리 끝내두는 것**입니다.
QR코드가 없으면 키오스크를 못 씁니다.

<img src="/assets/images/tips/visit-japan-web/vjw14.webp" alt="Visit Japan Web 앱의 입국심사 및 세관신고 메뉴 화면" width="1200" height="2186" loading="lazy" />

위 화면처럼 **'입국심사 및 세관신고'가 미등록으로 떠 있으면 QR코드가 안 나옵니다.**
여기까지 다 채워야 키오스크에 찍을 QR코드가 생깁니다.

등록 방법은 전에 화면 하나하나 찍어서 정리해둔 글이 있습니다.
→ [Visit Japan Web 등록 방법 정리](/posts/visit-japan-web/)

그리고 도착해서 QR코드를 띄워야 하니까, 휴대폰 배터리랑 데이터(유심·eSIM·로밍)도 미리 챙겨두세요.
