12월 17일 이후에 출발하는 아시아나항공을 예약해두셨다면, 11월에 문자 하나를 받게 됩니다.
아시아나 예약이 대한항공으로 넘어가면서 **편명이 OZ에서 KE로 바뀐다**는 안내입니다.

연말 여행 잡아두신 분들이 꽤 많을 것 같아서, 뭐가 바뀌고 뭘 확인해야 하는지 정리해봤습니다.

## 예약 이관 일정

[대한항공이 9월 14일에 발표한 내용](https://news.koreanair.com/대한항공-통합-항공사-출범-준비-본격화-아시아나항/)입니다.

| 구분 | 내용 |
| --- | --- |
| 대상 | 12월 17일 이후 출발하는 기존 아시아나 예약·항공권 |
| 이관 작업 기간 | 11월 2일 ~ 12월 3일, 순차 진행 |
| 바뀌는 것 | 아시아나(OZ) 편명 → 대한항공(KE) 편명 |
| 안내 방법 | 알림톡·문자·이메일로 개별 발송 |
| 공통 안내 | 대한항공 홈페이지·앱의 통합 FAQ |

여기서 헷갈리기 쉬운 게 하나 있습니다.
**11월 2일~12월 3일은 예약을 옮기는 작업 기간**이지, 여행 날짜가 아닙니다.
11월에 안내 문자를 받았다고 비행 날짜가 바뀌는 건 아니니 놀라지 않으셔도 됩니다.

그리고 왕복 일정이 12월 17일을 사이에 걸쳐 있다면, 가는 편과 오는 편을 따로 보셔야 합니다.
한 예약으로 묶여 있어도 각 구간의 출발일 기준으로 처리될 수 있어서, 안내가 오면 구간별로 하나씩 대조해보세요.

먼저 예약에 등록된 **전화번호랑 이메일**이 지금 쓰는 게 맞는지 확인해두세요.
안내가 그쪽으로 오기 때문입니다.
여행사에서 발권하셨다면, 변경 안내가 본인한테 오는지 여행사로 가는지 한 번 물어보시는 게 좋습니다.

기존 전자항공권이랑 결제 내역도 캡처해두세요.
나중에 새 예약이랑 비교할 때 날짜, 구간, 좌석까지 한 번에 대조할 수 있어서 편합니다.
가족 예약을 따로따로 했다면 예약별로 챙겨두시고요.

## 안내 받은 뒤 확인할 것

변경 안내를 받으면 아래 항목을 기존 예약이랑 나란히 놓고 보세요.
항공사가 이걸 다 바꾼다는 게 아니라, 혹시 달라진 게 있는지 확인하는 용도입니다.

| 확인 항목 | 볼 내용 |
| --- | --- |
| 항공편 | 편명, 출발 날짜·시간, 출발·도착 공항 |
| 탑승자 | 동행인 포함 영문 이름, 구간별 예약 |
| 연결편 | 환승 구간이 빠지지 않았는지, 시간이 바뀌지 않았는지 |
| 좌석·추가 서비스 | 지정 좌석, 추가 수하물, 특별 기내식 |
| 여행 일정 | 공항 픽업이나 숙소에 알려둔 도착 시간 |

출발 전에는 예약을 다시 한 번 열어보고, **최신 전자항공권**으로 저장해두세요.
예전에 찍어둔 캡처만 보고 공항 가면 바뀐 내용을 놓칠 수 있습니다.
시간이나 공항이 바뀌었다면 픽업이나 숙소 쪽에도 알려야 하고요.

아쉽게도 이번 발표에는 **지정 좌석, 사전 구매 수하물, 특별 기내식**을 어떻게 옮기는지는 안 나와 있습니다.
그대로 넘어간다고도, 다시 결제해야 한다고도 아직은 말하기 어렵습니다.

돈 내고 산 서비스가 있다면 영수증을 새 예약이랑 꼭 대조해보세요.
빠져 있거나 다르게 나오면, 다시 결제하기 전에 항공사나 발권처에 먼저 문의하시는 게 맞습니다.
문의할 때는 기존 예약번호, 탑승일, 빠진 항목을 같이 말하면 훨씬 빨리 해결됩니다.

참고로 편명이 바뀐다고 해서 **무료 변경이나 환불이 된다는 뜻은 아닙니다.**
변경·환불 조건은 각자 산 항공권 규정을 따르니 이것도 따로 확인해주세요.
