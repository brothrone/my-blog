태국 여행 가는 비용이 조금 더 늘어날 것 같습니다.
**태국 정부가 외국인 관광객에게 1인당 450바트(약 1만9000원)의 관광세를 걷는 방안**을 다시 추진하고 있어요.

아직 확정은 아닙니다.
지금은 의견 수렴 단계이고, **내각 승인까지 받아야 시행**됩니다.
다만 정부 목표는 **2027년 1분기, 항공 입국자부터**라서 내년 초 태국 여행 계획이 있다면 알아두시는 게 좋아요.

## 지금까지 나온 내용

| 항목 | 내용 |
| --- | --- |
| 금액 | **1인당 450바트** (입국 방법 상관없이 동일) |
| 대상 | 외국인 관광객 |
| 시작 목표 | **2027년 1분기, 항공 입국자부터** |
| 육로·해로 입국 | 그 뒤 약 360일 후 단계적으로 |
| 한 번 내면 | **30일 동안은 여러 번 드나들어도 다시 안 냄** |
| 쓰는 곳 | 관광객 보험(안전·건강), 관광지 개발 등 |
| 현재 단계 | **9월 28일까지 의견 수렴** → 위원회 재심의 → 내각 승인 |

[더 네이션](https://www.nationthailand.com/news/tourism/40070950) 등 태국 현지 보도 기준입니다.
태국 국가관광정책위원회가 8월 14일 초안을 승인했고, 관보에 고시된 날부터 **180일 뒤에 징수를 시작**하는 구조예요.

그러니까 아무리 빨라도 **고시 후 반년은 지나야** 실제로 걷습니다.
지금 예약하는 올겨울 태국 여행은 해당이 없다고 보시면 돼요.

## 전에는 300바트였는데

예전 안은 **항공 입국 300바트, 육로·해로 150바트**였습니다.
이번엔 입국 방법 상관없이 450바트로 합쳤어요. 비행기로 가는 한국 여행객 입장에서는 **150바트가 더 오른 셈**입니다.

태국 관광체육부 설명으로는 물가랑 비용을 반영해서 계산하면 490바트가 넘게 나왔는데, 부담을 줄이려고 450바트로 낮췄다고 합니다.

## 어떻게 내나

아직 안 정해졌습니다.
**항공권 값에 포함하는 방법, 웹사이트나 앱으로 내는 방법, 공항 무인기기** 등을 검토 중이라고 해요.

항공권에 포함되면 신경 쓸 게 없지만, 따로 내는 방식이 되면 **입국 전에 온라인으로 내야 할 수도** 있습니다.
시행이 확정되면 방법까지 다시 정리해드릴게요.

## 공항 이용료는 이미 올랐어요

관광세랑 별개로, **태국 공항 국제선 출국 이용료(PSC)는 6월 20일부터 이미 올랐습니다.**

| 항목 | 내용 |
| --- | --- |
| 금액 | **730바트 → 1120바트** |
| 적용 공항 | 수완나품, 돈므앙, 치앙마이, 치앙라이, 푸껫, 핫야이 (태국공항공사 6곳) |
| 적용 | 6월 20일 이후 발권한 항공권 |
| 내는 방법 | 항공권 값에 포함 |
| 국내선 | 130바트 그대로 |

[태국관광청 뉴스룸](https://www.tatnews.org/2026/05/airports-of-thailand-to-raise-international-passenger-service-charge-from-20-june-2026/) 기준입니다.
이미 항공권 값에 들어가 있어서 체감은 잘 안 되지만, 요즘 태국 왕복 항공권 세금이 좀 늘었다면 이것 때문이에요.

관광세까지 시행되면 **항공으로 드나들 때 공항 이용료 1120바트 + 관광세 450바트, 합쳐서 1570바트**가 되는 셈입니다.

## 정리하면

- 관광세 450바트는 **아직 추진 단계**이고, 빨라야 2027년 1분기
- 지금 가는 태국 여행은 **공항 이용료 인상분만** 적용 (항공권에 이미 포함)
- 관광세가 확정되면 시행일, 내는 방법을 따로 알려드릴게요
