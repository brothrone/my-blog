## 운항 일정

[에어프레미아의 9월 14일 공식 발표](https://company.airpremia.com/117/?bmode=view&idx=174129800)에 나온 일정입니다. 시각은 각 공항 현지 기준입니다.

| 항목 | 발표 내용 |
| --- | --- |
| 취항일 | 2026년 12월 2일 |
| 운항 요일 | 수·목·토·일 |
| 인천 → 신치토세 | 09:40 출발 → 12:20 도착 |
| 신치토세 → 인천 | 13:45 출발 → 17:15 도착 |
| 예정 기종 | 보잉 787-9 |
| 항공권 판매 | 9월 14일 오전 10시부터 홈페이지·앱 |
| 취항 기념 프로모션 | 9월 21일부터 예정 |

매일 운항하는 노선은 아니어서 숙소보다 왕복 항공편 날짜를 먼저 맞춰보는 게 좋겠습니다. 아래는 발표된 운항 요일로 조합한 여행 일정 예시입니다. 좌석이나 판매 여부를 확인한 상품은 아닙니다.

| 출발 → 귀국 | 여행 길이 |
| --- | --- |
| 목요일 → 같은 주 일요일 | 3박 4일 |
| 수요일 → 같은 주 일요일 | 4박 5일 |
| 토요일 → 다음 주 수요일 | 4박 5일 |

## 첫날과 귀국일 일정

신치토세 도착 시각을 곧바로 삿포로 시내 도착 시각으로 잡으면 일정이 빠듯해질 수 있습니다. 입국 심사와 짐 찾기, 숙소까지 이동하는 시간을 따로 잡아주세요. 첫날 유료 투어나 취소가 어려운 식당 예약을 넣는다면 특히 여유를 두는 편이 좋겠습니다.

귀국일도 공항 이동을 먼저 계산해보세요. 숙소 체크아웃 뒤 시내에서 얼마나 머물 수 있는지는 이용 교통편과 항공사 수속 마감 시각에 따라 달라집니다. 이 글에서는 공항까지 몇 분 걸린다고 일괄 계산하지 않았습니다.

## 결제 전 확인 사항

프로모션이 예고됐지만 **이 발표에는 할인 금액·종료일·대상 탑승 기간이 없습니다.** 9월 21일에 모든 날짜가 싸진다고 가정해서 숙소부터 확정하지는 마세요. 원하는 날짜가 정해져 있다면 현재 판매 조건을 기록해두고, 프로모션 상세 조건이 나온 뒤 비교하는 방법도 있습니다.

| 확인 항목 | 비교할 내용 |
| --- | --- |
| 왕복 총액 | 세금과 유류할증료를 포함한 최종 결제액 |
| 수하물 | 선택한 운임에 포함된 무게와 추가 요금 |
| 좌석·기내식 | 포함 여부와 별도 선택 비용 |
| 변경·환불 | 날짜 변경 비용, 취소 수수료와 적용 시점 |
| 실제 예약편 | 선택한 날짜의 운항 시각과 공항, 발권 조건 |

위 표는 예약할 때 확인할 항목이며 새로 발표된 요금 규정은 아닙니다. 보도자료에는 운항 종료일이나 날짜별 예외도 따로 적혀 있지 않습니다. 예약 화면에서 여행 날짜의 왕복편과 운임 조건을 확인한 뒤 결제해주세요.
