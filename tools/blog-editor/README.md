# Brothrone Editor

## 새 사진의 GPS 제거

Editor의 사진 추가/업로드는 새로 저장한 복사본에만 ExifTool을 실행하여 EXIF GPS와 XMP EXIF GPS 필드를 제거합니다. 기존 폴더의 사진이나 이미 발행된 사진을 일괄 처리하지 않습니다. 이미지 재압축은 하지 않으며 촬영일·색상 프로필 등 다른 메타데이터를 유지합니다.

이 Mac에서는 `.blog-editor/exiftool-runtime/Image-ExifTool-13.55/`의 검증된 공식 ExifTool을 사용합니다. 다른 Mac에서는 `exiftool`을 설치해야 합니다. 도구가 없거나 제거에 실패하면 해당 업로드를 실패 처리합니다.

## 경험을 바탕으로 글 준비하기

`AI 작성` 탭에서 방문·탑승 시기, 실제 비용, 예약 조건, 구체적인 경험, 장단점, 추천 대상, 확인 자료·확인일, 비용 지원 여부, 관련 글을 입력합니다. 게시일과 방문일은 별개이며 모든 항목은 선택 사항입니다. 사진이 없어도 메모를 먼저 작성할 수 있습니다. 기존 `기본 정보` 메모는 그대로 보관됩니다.

메모는 `.blog-editor/notes/{slug}.json`과 `.md`에 저장됩니다. Markdown에는 한국어·영어에 같은 사실을 반영하고, 모르는 정보는 만들지 않으며, 실제 경험과 외부 자료를 구분하도록 작성 기준이 포함됩니다. 빈 핵심 항목은 추가 확인 목록으로 표시합니다. 메모 저장만으로 AI를 호출하거나 게시하지 않습니다. 저장 후 Codex에 “메모 다 적었어”라고 알려주면 작성 작업을 이어갈 수 있습니다.

저장 실패 시 입력 내용과 재시도 상태를 유지합니다. 앱을 닫기 전에는 `메모 저장`의 성공 표시를 확인하세요. 수정된 화면과 서버는 Editor 앱을 완전히 종료한 뒤 다시 열면 적용됩니다.

검증: `/usr/bin/python3 tests/editor-notes-test.py`
