2026-09-15 사용자 승인에 따라 검수 완료 후 별도 승인 없이 자동 발행한다. 한국어는 `_posts/news/`, 영어는 `_en_posts/news/`에 저장한다. category: news, hidden: true, sitemap: true와 적절한 한·영 레이아웃, description, 상호 언어 링크를 넣는다. hidden은 페이지네이션 제외용이며 검색 차단 설정이 아니다. `_config.yml`의 폴더 기본값도 이를 보장한다.

## 문체

사용자가 쓴 기존 후기 몇 편을 읽고 본문은 짧고 편한 존댓말을 쓴다. 본문에서 반말 종결(한다, 이다, 하자)은 쓰지 않는다. 소제목에는 존댓말을 쓰지 않고 “예약 이관 일정”, “변경 후 확인 사항”처럼 간결한 명사형을 쓴다. 과장된 수식어, 홍보 문장, 상투적인 AI 표현, 이모티콘을 쓰지 않는다. '특별한 경험', '완벽한 선택', '매력적인 여행', '새로운 지평' 같은 빈말 대신 무엇이 바뀌었는지 구체적으로 쓴다. 실제 경험이 없는 뉴스에는 체험담을 만들지 않는다. 한국어와 영어 모두 자연스럽게 쓰되 정확성을 유지한다.

2026-10-03 사용자 지시에 따라 인터넷의 관련 공식 사이트를 Computer Use로 직접 열고 화면을 캡처한다. 자체 제작 이미지·생성 이미지·자체 도표 이미지·기존 블로그 사진을 사용하지 않는다. 캡처는 해당 문단을 설명하는 제품 식별 자료나 공지의 필요한 부분으로 한정한다. 캡처했다고 이용 허락이 생기는 것은 아니므로 원 사이트의 이용 조건과 권리 표기를 확인한다. 자유 이용 사진의 라이선스와 설명 목적의 출처 명시 화면 인용을 구분하고, 확인하지 않은 상업 이용 허락이나 CC 라이선스를 만들어 적지 않는다. 출처 URL·권리자·캡처일·사용 근거를 credits.json과 sources.json에 기록한다. 캡션은 대상·장소와 필요한 출처만 짧게 쓴다. “이 글의 사진은 모두 이전 여행에서 찍은 사진이다” 같은 글 자체에 대한 해설은 넣지 않는다. 다른 장소에서 촬영한 항공기 사진은 실제 촬영 장소를 명시한다.

## 사진·내용 필수 검수

모든 정보·뉴스 글은 본문에 서로 다른 관련 사진을 최소 3장 넣는다. 대표 이미지와 본문에서 같은 사진을 반복한 것은 두 장으로 세지 않는다. 한국어·영어 모두 적용한다. 직전 기사 사진을 편의상 재사용하지 않는다. 항공사·공항·객실·목적지 등 해당 문단과 직접 관련된 사진을 각각 고르고 실제 이미지를 열어 확인한다. 수량을 채우기 위한 무관한 사진, 다른 항공사 사진, 같은 사진의 잘라낸 변형은 금지한다. 관련성과 이용 조건을 충족하는 직접 캡처한 이미지 3장을 확보하지 못하면 발행 준비 완료로 처리하지 않는다. 촬영 시점·장소를 오해하지 않도록 필요한 경우 캡션에 표기하고 출처·촬영자·라이선스를 보관한다.

일정·대상·조건·비교·예약 확인 사항처럼 표로 읽기 쉬운 정보는 표로 정리한다. 기사에는 여행자가 실제로 확인할 항목과 구체적인 영향을 담되 분량을 늘리기 위한 미사여구는 쓰지 않는다. 공식 발표로 확인된 사실, 작성자의 제안, 아직 확인되지 않은 사항을 구분한다. 중요한 수치·날짜·대상·예외를 공식 원문과 대조하고, 공개 전 두 언어의 본문 사진 3장 이상·관련성·표·출처 링크·사실 일치를 검수한다.

대표 이미지는 제목의 핵심 주제를 직접 보여주는 공식 사이트 캡처를 선택한다. 대표 이미지·본문 첫 이미지·카테고리 썸네일·공유 메타데이터를 모두 확인한다. 스타링크 기사에는 스타링크 장비·서비스 등 관련 화면을 사용하며 일반 항공기 사진으로 대체하지 않는다. 서로 다른 안내 자료를 캡처하고, 같은 화면의 잘라낸 변형으로 수량을 채우지 않는다.
